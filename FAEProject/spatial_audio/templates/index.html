    UNDER THE HOOD

    From voice to space.

    A modular Python foundation for the full conferencing system.

    01

    Audio sources

    Working: live voices from a call, speech demo clips, uploaded WAV/MP3/M4A files, or generated test tones. Stereo uploads are downmixed to mono.

    Implemented
    02

    Call transport

    Working between browsers on one network: WebRTC with Opus audio, one isolated stream per speaker, and a small Flask server that only passes the setup messages. The media path round-trip time is shown in the call panel. Calls across the internet and a one-way latency measurement are not built yet.

    Implemented locally
    03

    Spatial engine

    Working: the live studio uses the browser’s HRTF panner (left-right and front-back cues), distance loudness, four wall reflections, a reverb tail and a duller sound from behind. Each can be switched off to hear what it adds. The offline Python renderer uses equal-power panning, up to 0.6 ms interaural delay, distance and focus (no front-back cues).

    Implemented
    04

    Personal mixer

    Working: per-person volume, mute, focus and distance, summed stereo output with a limiter, and loudness matching between mono and spatial so the comparison is fair. Mono removes all directional cues.

    Implemented
    05

    Headphone playback

    Working: live playback in the browser with instant changes and left/right level meters; offline render and WAV download. Network latency has not been measured; the future one-way target is under 150 ms.

    Implemented
    ✓

    Self-test

    Measures the spatial engine in this browser: ear level differences, mirror symmetry, ear-to-ear delay and front-back difference.

    Verification
    ★

    Head tracking

    Working: turn your head with the slider, by dragging “You”, with the Q and E keys, or with a webcam (MediaPipe runs in the browser; no video leaves the computer). The room stays still and the voices move around you.

    Implemented
